## Общие проблемы

1. **Тексты**: Почти все тексты в YAML не совпадают с SCENARIO.md. Нужно перенести все тексты из SCENARIO.md.
2. **Привязка**: Сейчас через offer-код из mock_hris.json. Нужно на русские слова.
3. **pre_block**: Реализован жёстко в `_registration_callback` как 4 шага. Нужно переделать на отдельную последовательность P01-P09.
4. **d1_10_email**: Полностью отсутствует.
5. **Опросы**: Все опросы упрощены. Нужно добавить:
   - survey_day3: ветвления по b/c, HELP_BUTTONS
   - survey_2weeks: yesno + reason, scale10 + reason
   - survey_month2: multi с галочками, ветвления
   - survey_final: yesno + reason, scale10 + reason, ветвления b/c
6. **Таймлайн**: 25 ключей вместо 23. Некоторые ключи не соответствуют SCENARIO.md по смыслу.
7. **Редкие флаги**: Текущая эвристика в `_analyze_text` и `_save_answer` не совпадает со списком из раздела 2 инструкции.
8. **Тестовый режим**: Нет команд `/stages`, `/next`, `/jump`, `/reset`, `/me`, `/stats`.
9. **Ассеты**: Нет папки assets/, нет функции `find_asset`, нет `send_asset_or_stub`.
10. **HR-уведомления**: Нет поддержки DEMO_MODE для отправки в чат тестировщика, нет head-HR уведомлений.
